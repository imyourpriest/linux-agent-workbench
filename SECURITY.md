# Security policy

Do not report a suspected vulnerability in a public issue, pull request, candidate manifest, sample report, or project log.

The project does not yet have a public private-reporting address. Until one is established, stop the affected work and ask the human owner to create a private reporting route. Do not include exploit details or secrets in chat or public files.

This project does not authorize scanning or probing deployed third-party services. The tools here perform bounded static analysis of local, explicitly public source checkouts and synthetic fixtures.
