# Inert public policy audit demonstration

This isolated Support Agent Regression Lab subproject demonstrates a deterministic audit report for
one project-owned synthetic public-repository policy fixture. It is distinct from the canonical
`policy-starter/` pack. The production module makes no network call, checkout, authentication
request, subprocess, shell invocation, model call, issue submission, ruleset change, outreach
action, or service activation. On Windows, one platform-bound test invokes `cmd.exe /c mklink /J`
solely to create a temporary junction and removes it after verifying rejection; this is test-fixture
setup, not production-module behavior.

The output is a cautious evidence table, explicit gaps, human decisions, patch-ready text
suggestions, manifest, and provenance receipt. It has no score or grade. It is not legal, security,
compliance, detection, certification, source-truth, authority, current-permission, adoption, or
enforcement evidence. The production verifier binds the exact synthetic input filenames and bytes
to module-owned SHA-256 constants before issuing a checked-tree result. This proves only equality
to the reviewed local fixture. It does not prove real ownership, authorship, or authority. Generated
manifest and receipt hashes are self-consistency fingerprints, not signatures or external trust
anchors.

Only the checked-in project-owned synthetic `input/` is eligible now. Later customer-approved
public input remains stopped until SEL-GH-001 has a final capture, a new control decision expressly
authorizes the next unit, and prospective acquisition, privacy, rights/terms, retention, and
provenance validation is designed and reviewed. This module contains no real-input mode.

The existing `$79` policy-starter-with-one-revision amount may remain a clearly unvalidated future
hypothesis; this demonstration is not a listing, forecast, offer activation, checkout, sale, order,
customer, or revenue event. Revenue remains `$0.00`.

Regenerate and check from `support-eval-lab/`:

```sh
python -m support_eval_lab.public_policy_audit --project .
python -m support_eval_lab.public_policy_audit --project . --check
```

The provided project directory is an explicitly trusted, non-adversarial parent boundary. The
module rejects link, junction, and reparse components from that project boundary through the audit
directory and rechecks the directory chain and output leaf before replacement. These checks reduce
accidental aliasing but do not make the workflow race-proof if an adversary can replace the trusted
project parent or its components concurrently.
