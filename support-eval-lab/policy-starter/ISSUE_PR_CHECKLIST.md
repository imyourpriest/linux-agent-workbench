# Synthetic issue and pull request checklist

- [ ] I identified material AI assistance in the pull request description.
- [ ] A human reviewed and understands every proposed change.
- [ ] I ran the repository's documented tests and reported the exact results.
- [ ] I checked authorship, license, and third-party provenance.
- [ ] I included no secrets, private data, or confidential material.
- [ ] I found no suspected vulnerability requiring private reporting.
- [ ] I am not treating this checklist as permission, identity proof, or maintainer approval.

This checklist records assertions for human review; it does not verify them.
