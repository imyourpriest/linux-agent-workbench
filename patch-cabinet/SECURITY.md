# Security policy

Do not open a public issue for a suspected vulnerability in Patch Cabinet or an upstream
candidate.

For a vulnerability in this project, use the root security policy and the repository's private
**Report a vulnerability** route. If that route is unavailable, stop without disclosing details
publicly. For a suspected upstream vulnerability, use only that upstream project's private
security process. Never include exploit details, secrets, private repository material, or
embargoed information in public logs.

Patch Cabinet does not authorize probing deployed services. Reproduction is limited to
project-owned fixtures or local, isolated copies of explicitly licensed public source.
