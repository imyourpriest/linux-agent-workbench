# Security policy

Do not open a public issue for a suspected vulnerability in Patch Cabinet or an upstream candidate.

Before a public hosting/contact route exists, stop work, record only a redacted local note, and ask the human owner to establish a private channel. Never include exploit details, secrets, private repository material, or embargoed information in the public logs.

Patch Cabinet does not authorize probing deployed services. Reproduction is limited to project-owned fixtures or local, isolated copies of explicitly licensed public source.
