# Declaration projection contract v1

This isolated record maps every authoritative top-level declaration field and every controlled
dimension exactly once by JSON Pointer. The verifier owns the allowed pointer/disposition mapping;
the accepted synthetic declaration supplies source values. Generated Markdown is comparison output,
never the semantic source.

The projection is inert and requires human review. It does not establish identity, authority,
currentness, permission, enforcement, or adoption. A `not_declared` source value can never become a
contributor obligation or checklist item.
